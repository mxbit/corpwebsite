# MXBit Website

A modern, responsive website built with React and Vite.

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## Customization

To match your Figma design, you can customize:
- Colors in `tailwind.config.js`
- Component layouts in `src/components/`
- Styling in `src/index.css`
- Content in each component file
